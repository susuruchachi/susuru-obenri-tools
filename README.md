# susuru-obenri-tools

ちょっと便利な道具箱。

## kashikari/ — きょうだい貸し借り帳

きょうだい（複数人）でのお金の貸し借りを記録・共有するページ。

- 公開先: https://claude.ai/artifact/8wjouRjkGeDGatC5FtCBy7 （claude.ai のアーティファクト。共有された人だけが開ける）
- 記録は全員が見られるが、書き込み・修正・削除できるのは**貸した本人だけ**（オーナーも他人の記録は変更不可）
- 1人が何人かにまとめて貸す「割り勘」記録に対応
- 返済は分割で何回でも記録でき、残額・完済を自動計算
- 「まとめ」で相手ごとの差し引き額と、全員の「だれがだれにいくら返すか」を表示

### データの置き場所

claude.ai アーティファクトの共有データベース（`db` capability）。

```
ledger/<userId>                 参加者（呼び名）
ledger/<userId>/loans/<loanId>  その人が貸した記録（返済履歴を含む）
```

アクセスルール: `ledger` は全員読み取り可・書き込みは本人のみ（`self`）、`ledger/{self}` 以下は本人が書き込み可。
